# Игра «Угадай число»

## Описание

Компьютер загадывает целое число от 1 до 100. Программа угадывает его за минимальное число попыток.

## Алгоритм

**Бинарный поиск** — делим диапазон пополам на каждом шаге.

### Идея:
1. Загадываем число.
2. Делим диапазон **пополам**.
3. Сравниваем середину с загаданным.
4. Сужаем диапазон вдвое.

**Сложность:** O(log n).

## Метрика

Среднее число попыток при 1000 повторений: **5 попыток**.
